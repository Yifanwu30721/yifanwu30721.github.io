# 我与翼神

## 为什么买翼神
2024年12月，和朋友一起去逛二手车市场，本来想要看一辆便宜的福特嘉年华，但后来发现网上的价格纯引流，实际价格贵得多。临走时，正巧看到了这辆保养的很好的三菱翼神，价格也合适，遂果断买下（详情请看cc98: https://www.cc98.org/topic/6062784，需浙大VPN登录）

## 我和翼神的故事
至今（2025年7月），我已经开着它走过了4000余公里，在杭州市内经历了紫金港-玉泉的无数次通勤，浙大的七个校区，除了之江校区外，我都开着它去过。在杭州市外，我们去了海宁、舟山，以及毕业后千里迢迢奔回福建。它总是有一些小毛病，比如车窗降不下来，天窗漏水等等，但我欣慰的是，它从没有把我撂在路上，很忠实，很可靠。
现在，它静静躺在我家小区的一隅，我偶尔也会去看看它。即将出国，多有不舍，希望这位老家伙能够给力一些，年检顺利，保险顺利，你若不离，我便不弃！
